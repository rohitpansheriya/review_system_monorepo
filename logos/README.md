# AppNexa Brand Assets & Guidelines

Official brand assets and vector source files for **AppNexa Technologies** and the **AppNexa** platform.

## 🎨 Brand Color Palette

| Token | Hex | RGB | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Navy** | `#00458B` | `0, 69, 139` | Primary Brand Color, App Headers, Primary Buttons |
| **Secondary Cyan/Blue** | `#00A3E0` | `0, 163, 224` | Accent Gradients, Highlights, Interactive States |
| **Pure White** | `#FFFFFF` | `255, 255, 255` | Dark Backgrounds, Footers, Reverse Lockups |
